# allan-valin.github.io

Portfolio site, served by GitHub Pages at <https://allan-valin.github.io/>. Plain HTML, no build step.

- `index.html`: the home page (English). `de/` and `pt/` hold the German and Brazilian Portuguese versions of every page, with the same paths.
- `cv/`: standard CV (`index.html`) and academic CV (`academic.html`).
- `assets/`: shared stylesheet and the flag icons of the language switcher.
- `poketype/`: browser version of PokeType.
- `papers/`: PDFs linked from the Research section.
- Photos are loaded from the `Multimedia-Projects` repo.
